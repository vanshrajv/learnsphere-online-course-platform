# 🎓 LearnSphere — Online Course Platform

LearnSphere is a modern and responsive **Online Course Platform** built with **React.js**. It provides an interactive learning experience where users can explore courses, enroll in courses, track their learning progress, take quizzes, and earn certificates.

The project focuses on a clean UI, responsive design, and smooth animations to create a professional e-learning experience.

## ✨ Features

* 🏠 Modern Landing Page
* 📚 Browse Online Courses
* 🔍 Course Search & Filtering
* 📖 Course Details
* ▶️ Online Learning Interface
* 📊 Learning Progress Tracking
* 📝 Interactive Quiz System
* 🏆 Course Certificates
* ❤️ Wishlist
* 👤 User Profile
* 🔐 Login & Registration UI
* 📋 My Courses Dashboard
* 🌙 Dark Mode
* 🎬 Smooth CSS Animations
* 📱 Fully Responsive Design
* ⭐ Course Ratings
* 🎯 Interactive Buttons & Cards

## 🛠️ Technologies Used

* React.js

* React Router DOM

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/learnsphere-online-course-platform.git
```

### 2. Open Project

```bash
cd learnsphere-online-course-platform
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL displayed by Vite in your browser.
